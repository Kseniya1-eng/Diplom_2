## Задание 2: Автотесты для API

### Автотесты для API Stellar Burgers

Протестированы эндпоинты:

- **Создание пользователя** (`POST /api/auth/register`):
  - создание уникального пользователя;
  - создание пользователя, который уже зарегистрирован;
  - создание пользователя без одного из обязательных полей.

- **Логин пользователя** (`POST /api/auth/login`):
  - вход под существующим пользователем;
  - вход с неверным логином и паролем.

- **Создание заказа** (`POST /api/orders`):
  - с авторизацией;
  - без авторизации;
  - с ингредиентами;
  - без ингредиентов;
  - с неверным хешем ингредиентов.

### Структура проекта

- `api` - клиенты для работы с API (user, order, endpoints)
- `helpers` - генераторы тестовых данных
- `tests` - тесты
- `allure-results` - результаты прогона для Allure-отчёта

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов с формированием результатов для Allure**

> `$ pytest --alluredir=allure-results`

**Формирование и открытие Allure-отчёта**

> `$ allure generate allure-results -o allure-report --clean`
>
> `$ allure open allure-report`
